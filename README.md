# hadgames — studio hub

This folder is the home base for Claude Code sessions. It holds no code —
every project lives in its own repo:

- `~/escapeSequence`, `~/wordQuilt`, `~/idleTavern`, `~/pocketTerrarium`,
  `~/pocketSnowGlobe`, `~/probeSwarm`, `~/marketShare`, `~/hallucination`,
  `~/daylightSavings`, `~/salvageRun`, `~/gridGame`, … (games)
- `~/Qualia App` (Qualia Signal app), `~/stocksim` (paper trader)
- `~/hadgamesSite` (privacy-policy site, GitHub Pages)

Open Claude Code HERE for day-to-day work — its cross-project memory
(all games' status, launch checklists, conventions) is keyed to this
folder. Opening a session directly inside a repo instead starts with a
blank, repo-local memory.

(History: sessions used to open in "~/Qualia App" because that was the
first project; memory was migrated here 2026-07-17.)
